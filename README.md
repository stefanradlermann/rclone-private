# rclone-private
RCCloneNutzung
Diese App wird ausschließlich privat von mir genutzt, um mit rclone auf mein eigenes Google Drive zuzugreifen. Es werden keine Daten gesammelt, gespeichert oder an Dritte weitergegeben.
Klicke oben rechts auf Commit changes und bestätige noch einmal mit Commit changes.
